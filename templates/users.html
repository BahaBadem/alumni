⚡ Terminalden cURL ile Test Komutları

1. GET /api/users (Tüm Bilgileri Listele):

curl -i http://127.0.0.1:8000/api/users/

2. POST /api/users (Yeni Kullanıcı Ekle):

curl -i -X POST http://127.0.0.1:8000/api/users/ \ -H "Content-Type: application/json" \ -d '{ "name": "Baha Badem", "birth_date": "2001-04-12", "city": "Ankara", "school": "Hacettepe Üniversitesi" }'

3. PUT /api/users/<id>/ (Tüm Bilgileri Tam Değiştir):

curl -i -X PUT http://127.0.0.1:8000/api/users/1/ \ -H "Content-Type: application/json" \ -d '{ "name": "Ahmet Baha Badem", "birth_date": "2001-04-12", "city": "İstanbul", "school": "İTÜ" }'

4. PATCH /api/users/<id>/ (Sadece İstenen Hücreyi Kısmi Değiştir):

curl -i -X PATCH http://127.0.0.1:8000/api/users/1/ \ -H "Content-Type: application/json" \ -d '{"city": "İzmir"}'

5. DELETE /api/users/<id>/ (Kullanıcı Kaydını Sil):

curl -i -X DELETE http://127.0.0.1:8000/api/users/1/
